 |
| **agent+KG+RAG** | 1. agent综合决策+KG结构化知识推理+动态检索
2. 支持复杂认知任务
3. 提供高解释性、可溯源的回答 | 1. 响应时间高，不适合高即时性的任务
2. 技术复杂度高
3. 系统调试难度高 | 1. 决策系统（如企业战略规划）
2. 企业宏观分析报告
3. 金融风控分析（借贷风控） |
